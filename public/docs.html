Firdavs Tours API

Pricing, departures and booking requests for the Firdavs Tours AI travel agent. The agent never calculates prices itself; it calls this API.

Checking status…

Endpoints

GET/api/tours

All 14 tours: id, name, days, cities, themes.

GET/api/quote?tour=classic-8&pax=2&class=comfort

Per-person price, single supplement (solo), total, custom-group flag (10+), includes / excludes.

GET/api/departures?tour=classic-group-8&from=2027-03-01

Upcoming fixed departures for the small-group tour; private tours run any date.

POST/api/requests

Saves a booking request and returns a reference like FT-MW3M4CBG8BM. Validated, rate-limited (5 / 10 min / IP), idempotent with an Idempotency-Key header.

GET/api/health

Uptime check: storage mode, tour count, server time.

Try it

curl "https://tours.fhsystems.dev/api/quote?tour=classic-8&pax=1&class=premium"
# {"ok":true,"quote":{"per_person_usd":6080,"single_supplement_usd":950,"total_usd":7030,...}}

How it is built

  • Node 20 serverless functions on Vercel, zero runtime dependencies
  • Upstash Redis for requests, rate limits and idempotency keys
  • Single source of truth for prices in lib/tours.json; 16 automated tests
  • Optional Telegram alert to the sales team on every new request
